# Тест из конспекта

Android-приложение, которое делает тест из обычного текста лекции. Вставляешь конспект,
выбираешь, сколько вопросов нужно, и проходишь тест. Работает без интернета и без нейросетей.

## Что умеет
- находит в тексте определения («Термин — это …») и спрашивает «Что такое …?» или наоборот «Как называется …?»
- прячет числа и даты, а в ответы подбирает похожие
- прячет длинные слова, а неправильные варианты берёт из других предложений конспекта
- после каждого ответа показывает предложение из конспекта, откуда взят вопрос
- в конце показывает результат и разбор ошибок
- запоминает последний вставленный текст

## Как установить
Открой раздел **Releases**, скачай `TestGenerator.apk` на телефон и установи
(Android спросит разрешение на установку из неизвестных источников — это нормально для приложений не из Play Market).

## Как собрать самому
APK собирается автоматически через GitHub Actions (файл `.github/workflows/build.yml`) при каждом пуше.
Локально: открыть папку в Android Studio и нажать Run, либо `gradle assembleDebug`.

## Из чего сделано
Kotlin, обычные Android Views + Material Components, minSdk 24 (Android 7.0).
Вся логика генерации вопросов лежит в `app/src/main/java/ru/study/testgen/TestGenerator.kt`.
